# Stakeholders of the GNSSTk

## Approvers
See the [GNSSTk CODEOWNERS file](https://sgl-git.arlut.utexas.edu/sgl-tks/gnsstk/-/blob/main/CODEOWNERS). To be added to this file as an approver submit a MR in that repository. To become a stakeholder of this PWI documentation, submit a MR adding yourself to ./CODEOWNERS
